- Hide and show the answer to each question by clicking the plus/minus icon
- Open and close each FAQ independently
- View the optimal layout depending on their device's screen size
- See hover and focus states for interactive elements

### What I Learned

This project helped me practice working with the DOM and JavaScript events.

I learned how to select multiple elements using `getElementsByClassName()` and add click events to them.

I also practiced using the event object to identify which FAQ item was clicked.
Another important thing I learned was the difference between `id` and `class`. Since the FAQ contains multiple questions and answers, classes are more appropriate for repeated elements.
