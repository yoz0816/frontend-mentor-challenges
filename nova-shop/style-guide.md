# Style Guide

## Colors

- Background: #F6F7F9
- Surface: #FFFFFF
- Primary: #2457E6
- Primary dark: #173DA8
- Heading: #171A21
- Body text: #606775
- Border: #E3E6EC
- Accent: #FFB84D
- Sale: #E85D75

## Typography

Use a clean modern sans-serif font.

- Heading: 700
- Subheading: 600
- Body: 400
- Button: 600

Suggested font:
- Inter

## Layout

- Desktop reference: 1440px
- Mobile reference: 375px
- Maximum content width: 1160px

## Border radius

- Product cards: 16px
- Buttons: 10px
- Images: 12px

## Spacing

Use multiples of 8px where possible.

## Breakpoints

- Desktop: above 1000px
- Tablet: 700px–1000px
- Mobile: below 700px
