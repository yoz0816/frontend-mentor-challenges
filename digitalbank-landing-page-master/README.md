### What I learned

#### 1. Building a responsive navigation

I practiced creating different navigation layouts for desktop and mobile.
On desktop, the navigation links are displayed horizontally.
On mobile, the desktop navigation is hidden and replaced with a hamburger menu.

#### 2. Creating a responsive hero sections
I learned how to change the hero layout from a two-column desktop design into a vertically stacked mobile layout.
