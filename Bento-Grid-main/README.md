### What I Learned

This project helped me improve my understanding of CSS Grid and responsive layouts. I learned how to position multiple cards using grid areas and combine Grid with Flexbox for aligning content inside each card. and I also learned how to manage overflowing images and create layouts that adapt to different screen sizes.
