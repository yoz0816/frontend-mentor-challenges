hi# Frontend Mentor - Blog preview card solution

This is my solution to the [Blog preview card challenge](https://www.frontendmentor.io/challenges/blog-preview-card-ckPaj01IcS) from Frontend Mentor.

I built this project to practice semantic HTML, CSS Flexbox, responsive design, and creating layouts that match a provided design.
