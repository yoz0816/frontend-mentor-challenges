### What I learned

During this project, I focused on creating a responsive layout that seamlessly transitions between mobile and desktop designs without breaking element positioning. 

Key learnings include:
1. **Custom Progress Bars:** Building a custom `div`-based progress bar instead of relying on default browser styling for `<progress>` elements, allowing full control over gradient fills and inner accent indicators.
2. **Absolute Positioning for Callouts:** Positioning the floating badge dynamically: centered at the bottom overlapping the card on mobile, and absolute-positioned with a speech bubble pointer on desktop.
