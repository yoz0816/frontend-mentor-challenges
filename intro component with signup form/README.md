## Overview

### The challenge

Users should be able to:

- View the optimal layout for the site depending on their device's screen size
- See hover states for all interactive elements on the page
- Receive an error message when the form is submitted if:
  - Any input field is empty
  - The error message says `[Field Name] cannot be empty`
  - The email address is not formatted correctly
  - The email error message says `Looks like this is not an email`

- Create responsive layouts using Flexbox

- Create custom error states
- Display error icons when validation fails
- Validate required form fields with JavaScript

- Change the appearance of inputs when they contain errors
