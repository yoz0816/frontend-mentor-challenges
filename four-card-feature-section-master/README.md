### What I learned

This project helped me practice creating a responsive layout using CSS Grid.

One of the main things I learned was how to position the four cards on desktop using grid rows and columns. The Supervisor and Calculator cards span two rows, while the Team Builder and Karma cards are stacked in the middle.
