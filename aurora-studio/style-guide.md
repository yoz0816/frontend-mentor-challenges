# Style Guide

## Layout
- Desktop width: 1440px reference
- Mobile width: 375px reference
- Content max-width: 1120px

## Colors
- Background: #F7F7FB
- Surface: #FFFFFF
- Primary: #6C63FF
- Dark: #1F2235
- Muted: #6B6F85
- Accent: #FFB86B

## Typography
Use a clean sans-serif font.
- Heading: 700
- Body: 400
- Button: 600

## Border radius
- Cards: 20px
- Buttons: 12px
- Large shapes: 28px

## Spacing
Use an 8px spacing system where possible.
