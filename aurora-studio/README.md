## Overview

### The challenge

Users should be able to:

- View the optimal layout for the site depending on their device's screen size
- See hover states for interactive elements
- View a responsive navigation layout
- See the hero section with text, button, and illustration
- View the statistics section clearly on different screen sizes

This project helped me practice creating a responsive landing page using semantic HTML and CSS.

I practiced using CSS Flexbox to create the header and hero section layouts.

I also learned how to use media queries to change the layout for tablets and mobile devices.
