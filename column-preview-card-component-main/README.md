### What I Learned

This project helped me practice:

* Building layouts with CSS Flexbox
* Creating responsive designs for desktop and mobile screens
* Using CSS media queries
* Working with custom Google Fonts
* Using `flex: 1` to create equal-width columns
* Using `margin-top: auto` to align buttons at the bottom of cards
* Creating hover states for buttons
* Using `border-radius` and `overflow: hidden` for the card container
* Organizing CSS into reusable selectors
